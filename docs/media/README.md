# README media

- `banner.png`: original illustrated fan artwork generated with the built-in image generation tool for this README. This image is promotional illustration, not a gameplay capture or official publisher artwork.
- `gameplay-exploration.gif`: ten seconds of live airport movement from the Linux release build, captured on 2026-10-18 at 480×320 and 12 frames per second.
- `gameplay-aiming.gif`: seven seconds of live aiming, firing and reloading from the same recording session, at 480×320 and 12 frames per second.
- `screenshot-airport.png` and `screenshot-aiming.png`: unmodified frames from those recordings. Desktop control mode hides the original touch action controls while preserving the phone shortcut and game HUD.
- `screenshot-title.png`: the previously reviewed native title-menu capture from local project qualification.
- The launcher screenshot linked from the root README is the existing capture in `docs/launcher/overview-1000x620.png`.

Gameplay was recorded on an isolated X11 display using a private copy of the locally imported English v1.03.00 installation and saves. The GIFs preserve the capture timing, loop, and use an optimized palette. Full-resolution frames, game data, logs and private save copies remain under the ignored `target/qualification/readme-media` directory; only rendered media is published.

Resident Evil Degeneration and its characters belong to their respective owners. No game executable, IPA archive, extracted game data, or save file is included with these media files.
