# Política de piratería de redegpc

[English](CODE_OF_CONDUCT.md) · **Español**

## Piratería

**⚠️ No enlaces contenido pirateado. El «abandonware» también se considera contenido pirateado.**<br>
**⚠️ No enlaces copias ilegales de aplicaciones que se publicaron gratuitamente. También se consideran contenido pirateado.**<br>
**⚠️ No preguntes cómo obtener contenido pirateado.**<br>
**⚠️ No hables sobre el uso de contenido pirateado.**<br>
**⚠️ Se te expulsará si ignoras estas advertencias.**<br>

Estas no son las únicas reglas sobre derechos de autor aplicables a redegpc. Lee también la [guía de contribución](CONTRIBUTING.es.md) si vas a aportar código.
